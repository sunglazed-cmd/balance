# Баланс — нативная Android-обёртка с фоновым шагомером

Это полноценный Android-проект (Capacitor + кастомный нативный плагин на Kotlin), который
даёт то, что невозможно в обычном веб-приложении: **шагомер, который работает в фоне** —
при выключенном экране, свёрнутом или полностью закрытом приложении, и сам возобновляется
после перезагрузки телефона.

## Что внутри

- `www/` — веб-приложение (тот же «Баланс», что и в браузерной версии)
- `android/` — нативный Android-проект (Capacitor)
- `android/app/src/main/java/com/balance/calorietracker/`:
  - `StepCounterService.kt` — foreground-сервис, читает аппаратный датчик
    `Sensor.TYPE_STEP_COUNTER` (сверхэкономичный чип, отдельный от основного процессора)
  - `PedometerPlugin.kt` — мост между JS-кодом приложения и нативным сервисом
  - `BootReceiver.kt` — автоматически перезапускает шагомер после перезагрузки телефона,
    если он был включён
  - `MainActivity.java` — регистрирует плагин

Веб-код в `www/index.html` сам определяет, что он запущен внутри нативной обёртки
(`window.Capacitor.isNativePlatform()`), и в этом случае использует настоящий фоновый
плагин вместо браузерного акселерометра. Если открыть тот же файл в обычном браузере —
он тихо откатится на прежний способ (датчик движения, только пока экран открыт).

## Как собрать APK

Нужен **Android Studio** (бесплатный, ставится на Windows/Mac/Linux):
https://developer.android.com/studio

1. Распакуй архив целиком в отдельную папку.
2. Открой терминал в этой папке и выполни:
   ```
   npm install
   ```
   (подтянет зависимости Capacitor — быстро, они уже прописаны в `package.json`)
3. Открой Android Studio → **Open** → выбери папку `android/` внутри распакованного архива
   (не корень, а именно `android/`).
4. Дай Android Studio время на первую синхронизацию Gradle (скачает SDK-компоненты,
   может занять несколько минут при первом запуске).
5. Подключи телефон по USB с включённой отладкой (Настройки → Для разработчиков →
   Отладка по USB), либо запусти эмулятор.
6. Нажми **Run ▶** — приложение соберётся и установится на устройство.

### Если хочешь просто установочный APK-файл (без USB)
В Android Studio: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
Готовый файл появится в `android/app/build/outputs/apk/debug/app-debug.apk` —
его можно переслать на телефон и установить напрямую (Android спросит разрешение
на установку из «неизвестных источников» — это нормально для несобранного через
Google Play приложения).

## Разрешения, которые попросит приложение

- **Физическая активность** (Activity Recognition) — обязательно для чтения датчика шагов
  на Android 10+
- **Уведомления** — обязательно на Android 13+, чтобы показывать постоянное уведомление
  «Баланс — считаем шаги» (без него Android не разрешает фоновым сервисам работать долго —
  это системное требование, не прихоть приложения)

## Если что-то не собирается

Скорее всего дело в версии Gradle/Android SDK на твоей машине — Android Studio обычно
предлагает автоматически подтянуть недостающее при первом открытии проекта (кнопка
«Sync Now» / «Install missing SDK component» в уведомлении сверху редактора). Собрать
это здесь, в чате, невозможно — сборка требует доступа к серверам Google, которого у меня
в этой песочнице нет, поэтому весь код подготовлен и проверен насколько возможно
(структура, синтаксис, манифест), но финальную сборку и первый тест на реальном железе
нужно делать на твоей стороне.
